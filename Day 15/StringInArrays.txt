========================================
       STRING IN ARRAY (Java)
========================================

1. What is String in Array ?
We can store multiple String
values in an array. Since
String is a class in Java, the
array will store references to
String objects. 

Syntax:
String[] arr = new String[size];

--------------------------------------------------

2. Declaration and Initialization

(i) Declaration
String[] arr;

(ii) Declaration with size
arr = new String[5];

(iii) Declaration and Initialization
String[] arr = {
    "Apple", "Banana",
    "Cherry", "Date"
};

--------------------------------------------------

3. Memory Representation

String[] arr = {"Red", "Green", "Blue"};

Index:   0        1        2
arr →  [   ]    [   ]    [   ]
          ↓        ↓        ↓
        "Red"   "Green"   "Blue"

Array stores reference to String objects.

--------------------------------------------------

4. Common Operations on String Array

| No. | Operation                           | Example                           | Code                                                                           | Output                         |
| --: | ----------------------------------- | --------------------------------- | ------------------------------------------------------------------------------ | ------------------------------ |
|   1 | **Declare and Initialize**          | `String[] arr = {"A", "B", "C"};` | `String[] arr = {"A", "B", "C"};`                                              | `A   B   C`<br>`(Index 0,1,2)` |
|   2 | **Access / Retrieve element**       | `arr[1]`                          | `System.out.println(arr[1]);`                                                  | `B`                            |
|   3 | **Update / Modify element**         | `arr[1] = "Green";`               | `arr[1] = "Green";`                                                            | `A   Green   C`                |
|   4 | **Traverse / Display all elements** | `Print all elements`              | `for(int i = 0; i < arr.length; i++)`<br>`    System.out.print(arr[i] + " ");` | `A   Green   C`                |
|   5 | **Length of Array**                 | `arr.length`                      | `System.out.println(arr.length);`                                              | `3`                            |

--------------------------------------------------

5. Taking Input in String Array

Scanner sc = new Scanner(System.in);

System.out.print("Enter size : ");

int n = sc.nextInt();

sc.nextLine();       // consume newline

String[] arr = new String[n];

System.out.println("Enter " + n + " strings:");

for(int i = 0; i < n; i++) {

    arr[i] = sc.nextLine();    // read full line
}

// nextLine() is used to read String with spaces.

--------------------------------------------------

6. Displaying String Array

System.out.println("Strings are :");

for(int i = 0; i < arr.length; i++) {

    System.out.println(arr[i]);

}

Example Output:
Apple
Banana
Mango
Orange

7. Useful Built-in Methods

(Applied on individual Strings)

| No. | Method                  | Description                      |
| --: | ----------------------- | -------------------------------- |
|   1 | `length()`              | Returns length of String         |
|   2 | `charAt(index)`         | Returns character at given index |
|   3 | `toUpperCase()`         | Converts to uppercase            |
|   4 | `toLowerCase()`         | Converts to lowercase            |
|   5 | `equals()`              | Checks content equality          |
|   6 | `equalsIgnoreCase()`    | Ignores case                     |
|   7 | `substring(begin, end)` | Returns part of String           |
|   8 | `contains(str)`         | Checks if part exists            |
|   9 | `compareTo(str)`        | Lexicographical compare          |

8. Example Program

// Program to demonstrate String in Array

import java.util.Scanner;

public class StringArrayExample {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter size : ");

        int n = sc.nextInt();

        sc.nextLine();

        String[] arr = new String[n];

        System.out.println(
            "Enter " + n + " strings :"
        );

        for(int i = 0; i < n; i++) {

            arr[i] = sc.nextLine();

        }

        System.out.println("\nStrings are :");

        for(int i = 0; i < n; i++) {

            System.out.println(
                (i + 1) + ". " + arr[i]
            );

        }
    }
}


Sample Run:
Enter size : 4
Enter 4 strings :
Apple
Banana
Cherry
Date

Strings are :
1. Apple
2. Banana
3. Cherry
4. Date

9. String Array with Fixed Values

String[] fruits = {
    "Apple",
    "Banana",
    "Mango",
    "Orange"
};

System.out.println(fruits[0]);
// Apple

fruits[2] = "Grapes";    // update

for(String f : fruits) {

    System.out.println(f);

}

--------------------------------------------------

10. Important Points

★ Arrays in Java are of fixed size.
★ Index always starts from 0.
★ String objects are stored in String Constant Pool.
★ Array stores reference to String objects.
★ Use nextLine() for taking String input.
★ We can perform all String class methods on array elements.
