==================================================
Topic - Polymorphism
==================================================

1. Introduction:

Polymorphism in Java means "one name, many forms". It allows objects of different classes to be treated as objects of a common superclass.


Example:

Shape s = new Circle();
s.draw();   // calls Circle's draw()


Shape s = new Rectangle();
s.draw();   // calls Rectangle's draw()
